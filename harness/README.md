# Harness

Reusable experimental tooling belongs here only after a concrete experiment requires it.

The harness follows a just-in-time rule: do not build a complete device emulator or generalized framework in anticipation of future needs. Start with the minimum behavior needed to discriminate the current hypotheses, then generalize only after repeated use demonstrates value.

Expected capability areas include normalized trace capture, BLE/peripheral test surfaces, differential comparison, and artifact instrumentation. These are capability categories, not mandatory components.
