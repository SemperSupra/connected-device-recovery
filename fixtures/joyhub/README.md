# JOYHUB Fixtures

This directory is reserved for sanitized, reproducible fixtures produced by the JOYHUB campaign.

A fixture belongs here only after:

1. its provenance is known;
2. sensitive/session-specific material has been removed;
3. the behavior it represents is reproducible;
4. the fixture is useful outside the private evidence repository.

Raw APKs, proprietary binaries, account/session captures, credentials, tokens, and unsanitized traces must not be committed here.
